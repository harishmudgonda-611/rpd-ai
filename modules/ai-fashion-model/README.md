# Module 02 — AI Fashion Model / Virtual Try-On

This module treats `Download/RPD AI Model` as the default RPD model library, scans assets, selects compatible models, and exposes a provider-neutral virtual try-on contract. It never fakes a generated result.

Open-source VTO implementations were evaluated; restricted licenses are not copied. A compatible local backend can be plugged in through `RPD_TRYON_COMMAND`.
