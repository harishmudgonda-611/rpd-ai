# Module 05 — Carousel Generator

RPD visual Instagram carousel renderer.

Open Carrusel is an MIT-licensed local-first carousel builder and a useful architectural reference. RPD does not copy its application code.

RPD output is 1080x1350 (4:5), supports 4-8 slides, and exposes five original RPD templates: editorial, pink-deal, minimal, lookbook and colour-grid.

The renderer is provider-neutral and cloud-free. A local browser adapter can render renderSlideHtml() into PNG/JPG/WebP. The default RPD AI model is supplied as an asset input; it is never a hardcoded remote image.
